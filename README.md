## Setup

This project uses Firebase.

Before running the app, you will need to:

1. Set up your own Firebase project.
2. Download your `GoogleService-Info.plist` file from Firebase.
3. Add `GoogleService-Info.plist` to the `BloomBoard` app folder in Xcode.
4. Add the Firebase iOS SDK package to the project using Swift Package Manager.
5. Make sure the `FirebaseAI` package/product is added to the BloomBoard target.

The `GoogleService-Info.plist` file is intentionally ignored by Git and should not be committed.
